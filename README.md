# 🤖 AI Mock Interview Platform

An AI-powered mock interview platform designed to help candidates practice interviews and receive personalized feedback. The application analyzes the user's resume, self-description, and job description to generate an AI-based interview report and performance score.

## 🚀 Features

- 🔐 User Registration and Login
- 🔑 JWT-based Authentication
- 📄 Resume Upload
- 🤖 AI-powered Interview Evaluation
- 📊 Personalized Interview Reports
- 🎯 Resume and Job Description Match Score
- 📝 Candidate Self-Description Analysis
- 🔒 Protected Backend APIs
- 📋 Interview Report History

## 🛠️ Tech Stack
